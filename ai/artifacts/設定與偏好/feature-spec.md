# 功能規格書

## Metadata

- 功能：每日新卡引入上限設定頁
- 負責人：Niko
- 狀態：草稿
- 風險等級：低

## 問題

「每日新卡引入上限」（`daily_new_card_limit`）目前是後端 `backend/app/core/config.py` 裡寫死的常數（20），Niko 想調整成 15，但現況要改這個值只能改程式碼、重新部署，沒有任何 UI 或 API 可以直接調整並持久化保存。

## 使用者

Niko（單機本地使用，唯一使用者）。

## 目標

- 提供一個設定頁面，顯示目前「每日新卡引入上限」的值。
- 可在設定頁調整這個值，儲存後立即套用到複習佇列 API（`/reviews/queue`），不需重啟伺服器。
- 設定值持久化保存（重新整理頁面、重啟後端伺服器後仍維持上次設定）。

## 非目標

- 不做 API 金鑰管理 UI（目前所有外部服務皆免金鑰，`LLM_API_KEY` 保留欄位完全未被任何功能使用，等真的有功能需要金鑰再開新 User Story）。
- 不做「預設語言視角」設定項（現有語言切換已透過前端 localStorage 記住上次選擇，下次開啟自動沿用，效果等同預設值，不需要額外的設定頁項目）。
- 不做獨立的「每日複習量目標／進度條」功能（與本設定不同概念，Niko 確認不需要）。
- 不做多組設定檔或多使用者設定（單機單一使用者）。
- 不做每語言（en/de）分別設定不同上限——沿用現況：同一個上限值分別套用在兩個語言各自的新卡計數（en 和 de 各自獨立計算今日已引入新卡數，但共用同一個上限數字）。

## 使用者故事（User Stories）

| 故事 | 身為／我想要／以便 | 驗收標準 |
|---|---|---|
| 每日新卡引入上限設定 | 身為 Niko，我想要在設定頁調整每日新卡引入上限，以便控制每天湧入複習佇列的新單字量，複習節奏更好掌握 | 設定頁顯示目前上限值（預設 15）；輸入合法正整數並儲存後，`/reviews/queue` 立即依新值計算新卡數量；重新整理頁面或重啟後端伺服器後，設定值仍保留上次調整結果 |

## 使用者旅程

```text
身為 Niko
我想要在設定頁把每日新卡上限從 20 調成 15（或其他數字）
以便新單字不會一次湧入太多，複習節奏可以自己掌握
```

## 功能需求

- WHEN 使用者開啟設定頁 THE SYSTEM SHALL 顯示目前的每日新卡引入上限值。
- WHEN 使用者輸入新的正整數並送出 THE SYSTEM SHALL 驗證輸入為介於 1～500 的整數，驗證通過則寫入持久化儲存並回傳更新後的值。
- WHEN 使用者輸入非法值（0、負數、超出範圍、非數字） THE SYSTEM SHALL 拒絕並顯示錯誤訊息，不變更目前設定值。
- WHEN `GET /reviews/queue` 被呼叫 THE SYSTEM SHALL 使用目前儲存的上限值計算可引入的新卡數量，而非讀取寫死的常數。

## 資料與 API

- 輸入：`PATCH /settings` `{ daily_new_card_limit: int }`
- 輸出：`GET /settings` -> `{ daily_new_card_limit: int }`
- 驗證：`daily_new_card_limit` 必須為 1～500 之間的整數
- 錯誤：驗證失敗回 422，附錯誤訊息
- 資料儲存：新增一張簡單的設定資料表（單列或 key-value），取代 `config.py` 常數作為 `daily_new_card_limit` 的實際來源；`.env`／`config.py` 的預設值僅作為資料庫尚無資料時的初始種子值。

## 安全性與隱私

- 身分驗證：不適用（沿用專案現況，單機本地無登入機制）。
- 權限：不適用。
- 敏感資料：無，純數字設定，不涉及金鑰或個資。
- 濫用情境：需限制輸入範圍（1～500），避免填入 0、負數或超大數字造成複習佇列查詢邏輯異常。

## 驗收標準

- 設定頁能查看與調整每日新卡引入上限，儲存後立即反映在 `/reviews/queue` 的新卡數量。
- 重啟後端伺服器或重新整理前端頁面，設定值不會被重置回程式碼寫死的預設值。
- 非法輸入被擋下並顯示錯誤訊息，不影響目前已儲存的設定值。

## 驗證計畫

- 單元測試：settings schema 驗證測試（合法值／非法值）。
- 整合測試：`GET`／`PATCH /settings` API 測試、`/reviews/queue` 套用新上限值的整合測試（含上限值變更後新卡數量正確反映）。
- E2E：無（沿用專案慣例，無 E2E 套件）。
- 視覺：設定頁截圖，對照既有 design-system 元件風格。
- 手動：Niko 本機操作設定頁，調整數值後在複習頁確認新卡數量符合預期，重新整理頁面確認設定保留。

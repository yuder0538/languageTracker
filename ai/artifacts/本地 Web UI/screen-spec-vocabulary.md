# 畫面規格

## Metadata

- 功能：本地 Web UI（Phase 4）／單字庫管理頁面
- 畫面：單字庫（Vocabulary）
- 狀態：草稿 | mockup 已核准 | 已實作 → **草稿，mockup 已產出待人工選定**

## 目的

讓使用者（Niko）能在網頁上看到目前語言視角（en/de）底下已有的單字，並新增單字進資料庫，不再需要透過 `http://127.0.0.1:8000/docs` 手動打 API。這是這一輪的範圍：**只做列表（唯讀）＋新增**，不含編輯、刪除、自動查字典/翻譯、CSV 匯入匯出（範圍見 `tools/kanban/epics.json` 的「單字庫管理頁面」User Story，2026-07-25 與 Niko 對話中確認）。

## 版面配置

兩個變體的版面配置不同（見下方變體比較），共同的內容區塊如下：

- 主要區域：單字列表表格（headword、詞性、翻譯、德文冠詞/複數若適用、建立時間）。
- 新增單字的輸入介面（兩變體位置不同：Dialog 彈窗 vs 常駐側欄表單）。
- 導覽：沿用 Dashboard 已建立的 icon rail（Dashboard／單字庫／追劇紀錄），「單字庫」項目改為真正可點擊導覽（本卡連動需要引入前端路由器，見任務卡）。
- 動作：新增單字、切換 en/de 語言視角（列表依語言重新查詢）。

## 狀態

| 狀態 | 必要行為 | 空狀態／錯誤文案 | 驗證方式 |
|---|---|---|---|
| 預設 | 顯示目前語言的單字列表 | — | 螢幕截圖 |
| 載入中 | 表格區顯示 skeleton 佔位 | — | 螢幕截圖 |
| 空狀態 | 目前語言完全沒有單字時 | 「還沒有任何單字，新增第一個吧」＋新增入口 | 螢幕截圖 |
| 錯誤 | 列表讀取失敗時，區塊顯示錯誤訊息＋重試按鈕，不影響新增表單 | 「讀取失敗，請重試」 | 螢幕截圖 |
| 停用 | 表單送出中，欄位與送出按鈕停用，按鈕顯示 loading 態（沿用 S4 `Button` 的 `loading` prop） | — | 螢幕截圖 |
| 權限不足 | 不適用（本機單人工具無權限分級） | — | — |
| 行動裝置版 | 表格橫向捲動（`overflow-x-auto`，沿用 S4 `Table` 元件既有慣例）；Dialog 變體天生適應窄螢幕，常駐側欄變體需改為欄位堆疊或表單移到表格上方 | — | 待選定版型後補截圖 |

## 互動

| 動作 | 觸發條件 | 結果 | 失敗情境 |
|---|---|---|---|
| 新增單字 | 填完必填欄位（headword）並送出 | 呼叫 `POST /api/v1/vocabulary`，成功後表格重新整理、toast 顯示「已新增『{headword}』」、表單清空 | 驗證失敗（如 headword 空白、德文特化欄位用在英文單字）在表單內顯示對應 `FieldError`；伺服器錯誤（422/500）顯示 toast 錯誤訊息，表單內容保留不清空 |
| 切換語言 | 點擊 EN／DE 切換（沿用 icon rail 既有樣式） | 表格重新查詢對應語言；新增表單的「德文特化欄位」（冠詞/複數/變位）依語言顯示/隱藏 | 讀取失敗顯示表格區的錯誤狀態 |
| 關聯追劇紀錄（選填） | 新增表單的「來源劇集」下拉選單 | 選填欄位，串接 `media_log_id`；若該語言目前沒有任何追劇紀錄，下拉選單顯示「尚無追劇紀錄」並停用 | 不適用 |

## 設計系統對照

- 用到的既有 design token：`color.bg.surface`／`color.border.default`／`color.accent.*`／`color.danger`／`radius.card`／`radius.control`／`space.card`／字級 scale。
- 用到的既有元件：`Table`、`Card`、`Button`（含 `loading` 態）、`Field`／`FieldLabel`／`FieldDescription`／`FieldError`、`Input`、`Select`、`Badge`（語言標籤）。皆為 S4 已完成的元件，直接重用。
- 本畫面新做的元件／視覺模式：無（若選定的版型需要 Dialog，`Dialog` 已在 S4 inventory；若需要常駐側欄卡片，屬既有 `Card` 元件的組合用法，不算新元件）。

## 視覺驗收標準

- 文字在手機版與桌面版都不會被截斷；表格過寬時橫向捲動而非擠壓內容。
- 「新增單字」是本畫面唯一的主要動作，視覺權重最高，清楚可見。
- 錯誤與空狀態明確呈現，且與列表區塊分開處理（列表出錯不擋住新增表單）。
- **色彩、字體、間距、圓角、陰影一律取自 `design-system.md` 的 design token，沒有硬寫的一次性數值。**
- **重複使用元件庫 inventory 裡的既有元件；任何新做的元件都依既有 token 與風格製作，且已登記回 inventory。**
